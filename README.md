# Naruto-Fanpage
Proyecto de landing page como trabajo final de Front-End.
Fanpage sobre el anime Naruto, aquí encontrarás contenido de los personajes, curiosidades del anime, galeria de fotos.
Se trabaja con las herramientas HTML5, CSS3 y JavaScript.
Para poder visualizar esta fanpage directamente desde tu escritorio, deberás descargar el .zip de este proyecto ubicado en la pantalla de inicio del repositorio; en tu explorador de archivos extraerás el contenido del .zip y abrirás con tu navegador de preferencia (o Microsoft Edge) el archivo index.html y asi podrás conocer más sobre Naruto!
